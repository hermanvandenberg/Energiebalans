Hoe de koppeling loopt

Wat je hieronder invult, versleutelt deze pagina met een sleutel die alleen GitHub Actions kan openen. Elke ochtend haalt GitHub de data op en zet hem, versleuteld met jouw wachtwoord, hier klaar.

jij→versleuteld→GitHub Actions→SolarEdge + Frank→dashboard
  • Laatst bijgewerkt: nog nooit
  • Voortgang en nu vernieuwen (Run workflow)
